# Code of Conduct

This project follows the Contributor Covenant v2.1 (https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful and constructive, welcome newcomers, accept feedback graciously, and never use this project's material against systems you are not authorised to test. Harassment, discrimination and abuse are not tolerated.

Report violations privately to the maintainers (GitHub Security Advisory) or the OWASP Siliguri chapter leads. Maintainers may remove comments, commits or contributors that violate this code.
