# Beginner labs

Guided walk-throughs. In the app choose **Beginner** mode: read the lesson, use the example
payload buttons, compare vulnerable and secure results, then read the Code tab.

Recommended order: llm01, llm02, llm10, llm03, llm05, llm04, llm06, llm07, llm09, llm08.

**Full written guides:** every module has a step-by-step guide in
[labs/guided](../guided/README.md) with the exact payloads, expected output, the flag
challenge, the Fix-It brief and a completion checklist. Each lab page in the app links
to its guide as well.
